# ELE_PRINCIPLE - Electronic Principles Project

## 项目概述
哈德斯菲尔德大学电子原理课程项目，包含实验报告和Multisim仿真结果。

```

│   └── EP1_group7_report.docx   # 实验报告Word版本
```

## 实验内容
- **实验名称**: EP1 Group 7 Report
- **课程**: Electronic Principles (ELE_PRINCIPLE)
- **小组**: Group 7

## 仿真说明
使用Multisim软件进行的电路仿真，包括：
1. 不同频率下的电路响应分析
2. 电位变化对电路性能的影响
3. 滤波器截止频率特性
4. 频率响应曲线

## 技术要点
- 主动滤波器设计
- 频率响应分析
- 电路仿真验证
- 实验数据记录与分析

## 使用工具
- Multisim - 电路仿真软件
- Microsoft Word - 报告撰写
- LaTeX/PDF - 文档格式化
